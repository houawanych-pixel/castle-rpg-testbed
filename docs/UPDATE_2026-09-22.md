# Visual + Audio Update — 2026-09-22

This build upgrades the original code-only mechanics testbed with self-contained original prototype assets.

## Added visual content
- Animated 32×32 main hero sprite sheet: four directions, four walk frames per direction.
- Animated 32×32 attack sheet for the hero.
- Four animated NPC variants that wander around outdoor/castle rooms.
- Enemy sprite atlas for the normal enemy archetypes and bosses.
- Original world-object atlas containing trees, bushes, rocks, houses, shop facade, pots, chests, and torches.
- Verdant Crossroads now contains houses/shop structures, foliage obstacles, and wandering NPCs.
- Outdoor rooms now use tree/bush/rock sprites as gameplay blockers and scenery.

## Added music
Original synthesized 16-bit-style WAV tracks:
- overworld.wav
- castle.wav
- cave.wav
- dungeon.wav
- boss.wav
- victory.wav

Room transitions automatically select an appropriate music track. Boss rooms select the boss track.

## Added sound effects
Original synthesized WAV effects for sword swing/hit, shield block, bow, boomerang, bomb, fire, ice, lantern, pickup, chest, secret discovery, door transition, switch, hurt, enemy hit/death, boss defeat, menu, footsteps, and swimming.

## Copyright / asset note
The playable assets in this ZIP were generated specifically for this mechanics test build. No Nintendo sprites, ripped Link sheets, Nintendo music, or Nintendo sound effects are included. User-supplied reference images were treated as visual/reference material and are not redistributed inside the project.

The files were assembled and statically inspected in this environment. A Godot 4.3 executable is not available in the current runtime, so this revision has not been truthfully engine-launched here. Import the project in Godot 4.3 and run it; if Godot reports a parser/import/runtime error, send the exact error and it can be patched in the ZIP.
