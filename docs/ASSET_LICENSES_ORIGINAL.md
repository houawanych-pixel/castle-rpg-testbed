# Asset provenance

The inherited prototype's original small PNG sprites and synthesized WAV music/SFX were created for the user's September 22, 2026 testbed. They are retained as source assets, with most displayed artwork replaced in this build.

New on September 23, 2026: `world_atlas_v2.png`, `hero_walk_v2.png`, and `cast_v2.png` were generated with the built-in imagegen tool specifically for this original Chronicle Clash prototype. Exact prompts are recorded in `ART_PROMPTS.md`. No third-party commercial-game artwork, characters, music, maps or code were downloaded for this build. No additional external asset pack is required. Generated artwork is not claimed to be an externally certified CC0 pack.

Terrain, UI, effects, sword trails and animation integration are drawn by the project code. The engine is Godot, distributed under its own MIT license; an engine binary is not included in this ZIP.
