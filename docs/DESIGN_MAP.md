# Testbed progression map

FIELD_0 Verdant Crossroads
- West/east-style linked exploration hub; grass, rocks, drops.
- Links toward meadow, castle, cave, and water branches.

FIELD_1 Windcut Meadow
FIELD_2 Old Stone Approach -> massive dungeon entrance
CASTLE_0/1 Amberkeep rooms -> indoor collision/pots/switches/chests
CAVE_0 -> cave interactions
CAVE_1 Torch Grotto -> darkness + lantern/torch behavior
WATER_0/1 -> shallow/deep water, swim-fins upgrade

DUNGEON_0 through DUNGEON_26
- Procedurally varied rooms containing push blocks, pits, ice floor, cracked bomb walls, torches, chests/switches.
- Boss chambers at 2,5,8,11,14,17,20,23,26.

Boss mechanics:
1. Miremaw — burrow/emerge/rush
2. Glasscoil — worm-like orbital motion
3. Ramhorn Warden — high-speed charges, recovery vulnerability window
4. Cinder Oracle — radial projectile patterns
5. Twinshade Archers — ranged spacing fight
6. Floodheart — water-themed fight with ice weakness
7. Thorn Engine — projectile rings, fire weakness
8. Prism Regent — alternating fire/ice vulnerability phases
9. Ninefold Colossus — combined charge, bullet ring, orbit, pursuit phases
