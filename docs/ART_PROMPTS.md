# Generated artwork

Built-in imagegen was used for the three new transparent PNG atlases. The game reads their atlas regions directly; the originals are included.

## Environment
`assets/environment/world_atlas_v2.png`

Use case: stylized-concept. Asset type: production sprite atlas for an original top-down fantasy mobile action RPG. Create one transparent PNG sprite atlas, landscape 2:1 aspect ratio, exactly 4 equal square columns by 2 equal square rows, no gaps or borders. Each cell holds exactly one isolated prop, centered horizontally, base at 85 percent height with plenty of transparent padding, nothing crossing cell boundaries. Row 1 left to right: lush old emerald oak tree with intricately clustered leaves and visible brown trunk, rounded flowering shrub, faceted blue-gray boulder with moss, cozy medieval cottage with blue slate roof and ivory plaster walls and wooden door. Row 2 left to right: fantasy shop with terracotta tiled roof and cream awning, ornate terracotta breakable pot, closed brass-trimmed wooden treasure chest, unlit iron standing torch brazier on wooden post. Style: very detailed hand-pixelled 32-bit JRPG game sprites, top-down three-quarter orthographic view (see roof and front), crisp limited palette shading, beautiful light from upper left, no isometric rotation, no text, no characters, no ground tile, no watermark. Transparent background required. Each object must be legible at 48x48 display pixels.

## Hero
`assets/sprites/hero_walk_v2.png`

Use case: stylized-concept. Asset type: transparent game-ready character walk animation sprite sheet, exact 4 columns x 4 rows of equal square cells, square image. Original top-down JRPG hero, blonde tousled hair, cobalt blue short adventurer coat, ivory shirt, brown leather boots and belt, small gold shoulder armor, no hat, no sword, no shield. Detailed crisp 32-bit pixel art, consistent anatomy, 3-head-tall compact chibi proportions. Orthographic top-down three-quarter view. Row 1 four frames facing DOWN toward viewer; row 2 four frames facing LEFT screen west; row 3 four frames facing RIGHT screen east; row 4 four frames facing UP showing BACK of head and coat. Each row exactly four walk-cycle poses: neutral feet together, left leg forward right leg back, neutral feet together, right leg forward left leg back. Keep same identity, clothing, scale, camera and centered anchor in every cell. One full-body isolated character per cell, uniform padding, no overlap. Transparent background, no floor, no shadows outside figure, no grid, no labels, no text, no extra characters.
